# فارما-كونكت (PharmaConnect)
نظام موزع لتتبع وفرة الأدوية وإدارة المخزون متعدد الصيدليات بنمط خادم وعميل

## وصف مختصر
يعالج نظام PharmaConnect أزمة تشتت بيانات المخزون الدوائي وعزلة الصيدليات في النطاق الجغرافي المحلي، والتي تجبر المرضى على خوض رحلات بحث ميدانية شاقة ومهدرة للوقت للعثور على أدويتهم الحرجة. يقدم النظام حلاً هندسياً متكاملاً يربط الصيدليات التجارية بمنصة مركزية موحدة تتيح البحث اللحظي عن الأدوية، تصفية النتائج جغرافياً، وحجز الدواء بمهلة زمنية مؤقتة (TTL) تمنع التزاحم وتضمن توافر الصنف عند وصول المريض للصيدلية.

## أعضاء الفريق
- **يعقوب المهاجري** - منسق الفريق وقائد هندسة الواجهات الخلفية (Team Coordinator & Backend Lead)
- **سليمان العربي** - مشرف المستودع ومسؤول لوحة الويب وتجربة الصيدلي (Repository Maintainer & Web Portal Lead)
- **مالك جبران** - مسؤول المتطلبات وقائد تطبيق الهواتف الذكية (Requirements Owner & Mobile Client Lead)

## التقنيات المستخدمة
- **Flutter (Dart 3.x):** تطبيق الهواتف الذكية والويب للعملاء (المرضى).
- **Laravel 11 (PHP 8.2+):** الخادم المركزي ومعالجة المنطق وتوفير واجهات RESTful APIs.
- **MySQL / SQLite:** إدارة البيانات العلائقية ومخزن الكاش المحلي لحالات العمل دون اتصال.
- **Git & GitHub:** إدارة الإصدارات، لوحات Kanban، وحوكمة المراجعات البرمجية.

## طريقة العمل
يتبع الفريق دورة هندسة برمجيات منضبطة تعتمد على تجزئة المتطلبات إلى **GitHub Issues**، والعمل في فروع مستقلة (**Feature/Docs Branches**)، وإجراء مراجعة الأكواد (**Code Review**) قبل دمج أي تغيير عبر **Pull Requests** وفق معايير الجودة المحددة في مقرر هندسة البرمجيات.
